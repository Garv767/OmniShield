# OmniShield Design System
* Framework: Next.js with Tailwind CSS and shadcn/ui.
* Aesthetic: Apple Developer or macOS system tool. Extreme minimalism, high contrast, typography-driven.
* Backgrounds: bg-slate-50 or bg-white.
* Text: text-slate-900 for primary elements, text-slate-500 for secondary descriptions.
* Borders: border-slate-200. Only use borders to separate logical groups; avoid boxing every element.
* Accents: Use pure system blue (bg-blue-500) strictly for primary actions. No purple, indigo, or neon colors.
* Typography: System sans-serif (Inter/Geist) for UI text. Use font-mono exclusively for IDs, IP addresses, and financial figures.
* Components: No heavy drop shadows. Rely on subtle frosted glass effects (backdrop-blur-md bg-white/70) for floating elements. Use 6px colored status dots (red/green) instead of fully colored background pills for alerts.
